## My Role

and network clients for the API to load properly. I was also in charge of the programs plugins, build tests, and versions.

## My Biggest Challenge
---
My biggest challenge was thinking of the structure itself, along with the re-encounter with Android Studio. The last time i worked in
Android Studio was CST 338. It was also in Java and XML, so zero Kotlin and Compose when i last worked with Android Studio. Furthermore, i wasn't sure how Kotlin should really be strucutured 
in the first place so it had me thinking of a structure idea for the first week of the project. The way i solved my challenge was thinking about how i strucuted my code in 336 (internet programming) which 
eventually gave me the idea on being able to develop a navigation file, which contained each files route and where it will lead next. It wasn't the same exact idea as EJS/MJS, but thinking of it that way helped
me develop what is now the programs actual structure and flow. i.e., we have a central file in charge of the routes, and then each of the app files access that same file for their parameters.
