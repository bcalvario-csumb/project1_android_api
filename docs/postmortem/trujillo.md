## Biggest challenge
- My biggest challenge was mostly trying to fix gradle.
- I was originally in charged to implement room, but there were a fix plugins that couldn't mix well together.
- This led to many people's gradles having issues, and it wasn't long before I too was affected.
- But in the end, we established a permanent gradle file, so that no one dares touch the gradle if absolutely necessary.
- I handled it by what was after. I began reading more about gradles, or rather started to learn more about them, so that my mistakes won't repeat again. 

## Most valuable thing I learned
- The most valuable thing I learned is this. Make sure to implement a build system, and everyone has to use said build system.
- A static gradle that no one touches is a good gradle, and will carry less issues.
